# Ducere — Artwork, Branding & Asset Provenance Audit

Last reviewed: 2026-09-20

## Purpose

Track what visual/content assets Ducere owns versus what it merely displays or references under a third-party license.

## Ducere-created assets

The following should be treated as Ducere-owned only where they were created by the project owner or a contributor who has assigned the relevant rights:

- original UI layouts and styling;
- original application screens;
- original product copy;
- original icons/illustrations created specifically for Ducere;
- original logo/wordmark artwork;
- original animations or interaction designs.

Keep source files and creation history for these assets.

## Third-party assets

These are not automatically Ducere-owned:

- movie posters;
- TV/anime artwork;
- backdrops;
- actor/character photographs;
- streaming-provider logos;
- streaming-provider names and trademarks;
- TMDB images/data;
- Watchmode third-party image URLs/data;
- any images copied from websites or search engines.

Public availability of an image does not mean it is public-domain or commercially cleared.

## Current app rule

Ducere should continue to treat availability and media metadata as source-backed information rather than claiming ownership of the underlying media.

The application already contains legal/credits pages and the availability layer is designed not to invent provider availability.

## Before commercial sale

For each visual asset used in the production product, record one of:

1. Ducere original — creator identified.
2. Licensed — license/source recorded.
3. API-provided — API terms recorded.
4. Provider trademark/logo — usage basis recorded.
5. Placeholder/fallback — provenance recorded.
6. Remove before commercial launch — if rights cannot be established.

## High-priority items

1. App logo/brand source files.
2. Streaming provider logos.
3. Poster/backdrop source and API terms.
4. Any manually downloaded images.
5. Fonts and icon sets.
6. Any screenshots used in marketing.

## Acquisition rule

An acquisition buyer should receive a clear asset schedule showing which assets are owned by Ducere and which are licensed from third parties. This avoids representing licensed media as owned IP.
